Windows USB drivers

In Device Manager, open Ports (COM & LPT). Choose the driver that matches your adapter’s name.

Silicon Labs CP2102

  1. On Windows 10 or 11, download the CP210x Universal Windows Driver and extract the ZIP file.
  2. In Device Manager, choose Update driver for the CP2102 adapter and point it to the extracted folder.

Prolific PL2303HX

  1. On Windows 10, follow the ZiGate instructions for the blue adapter, then restart the PC.
  2. On Windows 11, if you see PL2303HXA PHASED OUT, use the adapter on a Linux PC or fit the radio onto a ZiGate-compatible CP2102 adapter.

Keep an offline copy

Keep your adapter’s ZIP file with your ZiGate files. If your driver is already installed, you can also export it from Windows.

Export an installed driver
  1. Open Windows Terminal as an administrator and run pnputil /enum-drivers. Find the Silicon Labs or Prolific driver and note its published name, for example oem42.inf.
  2. Create a backup folder and run the command below with your own name and path.
pnputil /export-driver oem42.inf "C:\Pilotes-ZiGate"
