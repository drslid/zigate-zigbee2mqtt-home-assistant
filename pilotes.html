Pilotes USB pour Windows

Dans le Gestionnaire de périphériques, ouvre Ports (COM et LPT). Choisis le pilote qui correspond au nom de ton adaptateur.

Silicon Labs CP2102

  1. Sous Windows 10 ou 11, télécharge CP210x Universal Windows Driver et extrais le ZIP.
  2. Dans le Gestionnaire de périphériques, choisis Mettre à jour le pilote pour l’adaptateur CP2102 et indique le dossier extrait.
Télécharger chez Silicon Labs ↓ Catalogue Microsoft Update ↗

Prolific PL2303HX

  1. Sous Windows 10, suis la procédure ZiGate pour l’adaptateur bleu, puis redémarre le PC.
  2. Sous Windows 11, si Windows affiche PL2303HXA PHASED OUT, utilise ton adaptateur sur un PC Linux ou monte la radio sur un adaptateur CP2102 compatible ZiGate.

Garder une copie hors ligne

Garde le ZIP de ton adaptateur avec les fichiers de la ZiGate. Si ton pilote est déjà installé, Windows permet aussi de l’exporter.

Exporter un pilote installé
  1. Ouvre le terminal Windows en administrateur et lance pnputil /enum-drivers. Repère le pilote Silicon Labs ou Prolific et note son nom publié, par exemple oem42.inf.
  2. Crée un dossier de sauvegarde et lance la commande ci-dessous en remplaçant le nom et le chemin par les tiens.
pnputil /export-driver oem42.inf "C:\Pilotes-ZiGate"
